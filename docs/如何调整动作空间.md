# 如何调整动作空间（Hys/TTT 组合）

## 一、快速回答

### Q1: 48个动作是如何得出的？

**A**: 是的，48个动作 = **Hys 集合数量 × TTT 集合数量**

```
Hys 集合：8个值 [1.5, 2.0, 2.5, 3.0, 3.5, 4.0, 4.5, 5.0]
TTT 集合：6个值 [0, 40, 80, 160, 320, 640]
总动作数 = 8 × 6 = 48
```

### Q2: 如果调整参数组合，代码是否需要调整？

**A**: **现在不需要了！** ✅

我已经优化了代码，现在只需要修改配置文件即可，代码会自动适应。

## 二、如何调整动作空间

### 2.1 方法：修改配置文件（推荐）

只需修改 `configs/default_env_config.yaml`：

```yaml
action_space:
  hys_set: [1.5, 2.0, 2.5, 3.0, 3.5, 4.0, 4.5, 5.0]  # 修改这里
  ttt_set: [0, 40, 80, 160, 320, 640]  # 修改这里
```

**示例1：增加 Hys 值（48 → 60个动作）**

```yaml
action_space:
  hys_set: [1.5, 2.0, 2.5, 3.0, 3.5, 4.0, 4.5, 5.0, 5.5, 6.0]  # 10个
  ttt_set: [0, 40, 80, 160, 320, 640]  # 6个
  # 总动作数 = 10 × 6 = 60
```

**示例2：增加 TTT 值（48 → 64个动作）**

```yaml
action_space:
  hys_set: [1.5, 2.0, 2.5, 3.0, 3.5, 4.0, 4.5, 5.0]  # 8个
  ttt_set: [0, 40, 80, 160, 320, 640, 960, 1280]  # 8个
  # 总动作数 = 8 × 8 = 64
```

**示例3：减少参数值（48 → 20个动作，训练更快）**

```yaml
action_space:
  hys_set: [2.0, 3.0, 4.0, 5.0]  # 4个
  ttt_set: [0, 80, 160, 320, 640]  # 5个
  # 总动作数 = 4 × 5 = 20
```

### 2.2 代码会自动适应

✅ **环境代码**：自动从配置读取，计算动作数量
✅ **ActionSpace 类**：如果可用，会自动适应（需要更新以支持自定义参数）
✅ **模型代码**：需要手动修改 `num_actions` 参数（如果硬编码了）

## 三、需要修改的地方

### 3.1 ✅ 不需要修改（已自动适应）

- ✅ `envs/train_ho_env.py` - 自动从配置读取
- ✅ `envs/ho_logic.py` - 不依赖动作数量

### 3.2 ⚠️ 可能需要修改

1. **模型初始化**（如果硬编码了 `num_actions=48`）

```python
# 旧代码（硬编码）
model = RainbowWithForecast(
    obs_dim=10,
    num_actions=48,  # ❌ 硬编码
    ...
)

# 新代码（从配置读取）
import yaml
with open("configs/default_env_config.yaml") as f:
    config = yaml.safe_load(f)
hys_set = config['action_space']['hys_set']
ttt_set = config['action_space']['ttt_set']
num_actions = len(hys_set) * len(ttt_set)

model = RainbowWithForecast(
    obs_dim=10,
    num_actions=num_actions,  # ✅ 从配置读取
    ...
)
```

2. **配置文件中的注释**（可选）

`configs/model_config.yaml` 中的 `num_actions: 48` 只是注释，不影响功能，但建议更新以保持一致性。

## 五、总结

### ✅ 优势

1. **只需修改配置文件**：一次修改，全局生效
2. **自动计算动作数量**：无需手动计算
3. **代码自动适应**：环境代码会自动读取配置

### ⚠️ 注意事项

1. **模型初始化**：如果模型硬编码了 `num_actions`，需要修改
2. **ActionSpace 类**：如果需要完全自定义，可能需要扩展 `ActionSpace` 类以支持从配置读取

### 📝 建议

1. **统一使用配置文件**：所有参数都从配置文件读取
2. **避免硬编码**：模型初始化时从配置读取 `num_actions`
3. **文档同步更新**：修改配置后，更新相关文档
