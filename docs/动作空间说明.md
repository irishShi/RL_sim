# 动作空间说明：48个动作的由来和调整方法

## 一、48个动作的由来

### 1.1 计算方式

**48个动作 = Hys 集合数量 × TTT 集合数量**

根据模型方案文档：
- **Hys 集合**：8个值
  ```
  [1.5, 2.0, 2.5, 3.0, 3.5, 4.0, 4.5, 5.0] dB
  ```
- **TTT 集合**：6个值
  ```
  [0, 40, 80, 160, 320, 640] ms
  ```
- **总动作数**：8 × 6 = **48**

### 1.2 动作映射规则

动作索引通过**笛卡尔积**（Cartesian Product）生成：

```
动作索引 = Hys索引 × TTT数量 + TTT索引
```

**示例**：
- 动作 0: (Hys=1.5, TTT=0)    → 0 × 6 + 0 = 0
- 动作 1: (Hys=1.5, TTT=40)   → 0 × 6 + 1 = 1
- 动作 5: (Hys=1.5, TTT=640)  → 0 × 6 + 5 = 5
- 动作 6: (Hys=2.0, TTT=0)    → 1 × 6 + 0 = 6
- 动作 10: (Hys=2.0, TTT=160) → 1 × 6 + 4 = 10
- 动作 47: (Hys=5.0, TTT=640) → 7 × 6 + 5 = 47

## 二、如何调整参数组合

### 2.1 当前代码的问题

**硬编码的地方**：
1. `envs/train_ho_env.py` 第59行：`spaces.Discrete(48)` - 硬编码动作数量
2. `envs/train_ho_env.py` 第90-91行：硬编码 Hys 和 TTT 集合
3. `configs/model_config.yaml` 第7行：`num_actions: 48` - 硬编码动作数量

**问题**：如果修改 Hys 或 TTT 集合，需要手动修改多个地方。

### 2.2 改进方案

**方案1：从配置文件读取（推荐）**

在环境配置文件中添加动作空间配置：

```yaml
# configs/default_env_config.yaml
action_space:
  hys_set: [1.5, 2.0, 2.5, 3.0, 3.5, 4.0, 4.5, 5.0]
  ttt_set: [0, 40, 80, 160, 320, 640]
  # num_actions 会自动计算，不需要手动指定
```

**方案2：从 ActionSpace 自动获取**

如果 `ActionSpace` 可用，环境自动从它获取动作数量。

## 三、调整示例

### 3.1 示例1：增加 Hys 值

**修改前**：8个 Hys 值 → 48个动作
```python
hys_set = [1.5, 2.0, 2.5, 3.0, 3.5, 4.0, 4.5, 5.0]  # 8个
ttt_set = [0, 40, 80, 160, 320, 640]  # 6个
# 总动作数 = 8 × 6 = 48
```

**修改后**：10个 Hys 值 → 60个动作
```python
hys_set = [1.5, 2.0, 2.5, 3.0, 3.5, 4.0, 4.5, 5.0, 5.5, 6.0]  # 10个
ttt_set = [0, 40, 80, 160, 320, 640]  # 6个
# 总动作数 = 10 × 6 = 60
```

### 3.2 示例2：增加 TTT 值

**修改前**：6个 TTT 值 → 48个动作
```python
hys_set = [1.5, 2.0, 2.5, 3.0, 3.5, 4.0, 4.5, 5.0]  # 8个
ttt_set = [0, 40, 80, 160, 320, 640]  # 6个
# 总动作数 = 8 × 6 = 48
```

**修改后**：8个 TTT 值 → 64个动作
```python
hys_set = [1.5, 2.0, 2.5, 3.0, 3.5, 4.0, 4.5, 5.0]  # 8个
ttt_set = [0, 40, 80, 160, 320, 640, 960, 1280]  # 8个
# 总动作数 = 8 × 8 = 64
```

### 3.3 示例3：减少参数值（更精细控制）

**修改前**：48个动作
```python
hys_set = [1.5, 2.0, 2.5, 3.0, 3.5, 4.0, 4.5, 5.0]  # 8个
ttt_set = [0, 40, 80, 160, 320, 640]  # 6个
```

**修改后**：24个动作（更少的动作，训练更快）

```python
ttt_set = [0, 80, 160, 320, 640]  # 5个
# 总动作数 = 4 × 5 = 20（实际是20，不是24）
```

## 四、代码调整需求

### 4.1 需要修改的地方

如果调整参数组合，需要修改以下地方：

1. ✅ **`models/action_space.py`** - `ActionSpace` 类会自动适应（已实现）
2. ⚠️ **`envs/train_ho_env.py`** - 需要修改硬编码的动作数量
3. ⚠️ **`configs/model_config.yaml`** - 需要更新配置
4. ⚠️ **模型初始化** - 如果模型硬编码了 `num_actions=48`，需要修改

### 4.2 改进建议

**建议1：让环境从配置自动读取**

修改环境代码，从配置文件读取 Hys/TTT 集合，自动计算动作数量。

**建议2：统一使用 ActionSpace**

所有地方都通过 `ActionSpace` 获取动作数量，避免硬编码。

---

## 五、总结

### 5.1 48个动作的计算

✅ **48 = 8 (Hys) × 6 (TTT)**

### 5.2 调整参数组合

⚠️ **需要修改代码**，但可以通过改进让代码自动适应。

### 5.3 改进方向

1. 从配置文件读取参数集合
2. 自动计算动作数量
3. 统一使用 `ActionSpace` 类

这样可以实现**一次配置，全局生效**，避免多处修改。
