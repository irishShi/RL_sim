# 离线学习使用指南

## 概述

本项目已支持离线学习（Offline RL）模式，可以从预收集的数据集训练模型，无需与环境实时交互。

## 主要文件

1. **`collect_data.py`** - 数据收集脚本
2. **`train_rainbow_offline.py`** - 离线训练脚本
3. **`utils/dataset_loader.py`** - 数据集加载器

## 使用流程

### 第一步：收集数据

使用 `collect_data.py` 收集离线学习所需的数据集。

#### 基本用法

```bash
python collect_data.py --num_episodes 100 --output_path data/offline_dataset.npz
```

#### 参数说明

- `--num_episodes`: 收集的 episode 数量（默认：100）
- `--policy_type`: 收集策略类型（默认：`random`）
  - `random`: 完全随机策略
  - `epsilon_greedy`: Epsilon-greedy 策略
  - `fixed`: 固定策略（Hys=3.0, TTT=160）
  - `uniform_mix`: 均匀混合策略（随机选择 Hys/TTT 组合）
- `--epsilon`: Epsilon 值（用于 epsilon_greedy，默认：1.0）
- `--output_path`: 输出路径（默认：`data/offline_dataset.npz`）
- `--seed_start`: 起始随机种子（默认：0）

#### 示例

```bash
# 使用随机策略收集 200 个 episode
python collect_data.py --num_episodes 200 --policy_type random --output_path data/random_dataset.npz

# 使用固定策略收集数据
python collect_data.py --num_episodes 150 --policy_type fixed --output_path data/fixed_dataset.npz

# 使用均匀混合策略收集数据
python collect_data.py --num_episodes 300 --policy_type uniform_mix --output_path data/mixed_dataset.npz
```

### 第二步：离线训练

使用 `train_rainbow_offline.py` 从收集的数据集训练模型。

#### 基本用法

```bash
python train_rainbow_offline.py --dataset_path data/offline_dataset.npz
```

#### 参数说明

- `--dataset_path`: 数据集路径（默认：`data/offline_dataset.npz`）
- `--use_cql`: 是否使用 CQL（Conservative Q-Learning）正则化（推荐）
- `--cql_alpha`: CQL 正则化系数（默认：0.1）
- `--num_epochs`: 训练轮数（默认：100）
- `--samples_per_epoch`: 每轮采样数（默认：10000）
- `--batch_size`: Batch 大小（覆盖配置文件中的设置）

#### 示例

```bash
# 基础离线训练（不使用 CQL）
python train_rainbow_offline.py --dataset_path data/offline_dataset.npz --num_epochs 50

# 使用 CQL 的离线训练（推荐）
python train_rainbow_offline.py --dataset_path data/offline_dataset.npz --use_cql --cql_alpha 0.1 --num_epochs 100

# 自定义训练参数
python train_rainbow_offline.py \
    --dataset_path data/offline_dataset.npz \
    --use_cql \
    --cql_alpha 0.2 \
    --num_epochs 200 \
    --samples_per_epoch 20000 \
    --batch_size 64
```

## 数据集格式

数据集保存为 `.npz` 格式，包含以下字段：

- `obs`: 观测窗口 `[N, window_size, obs_dim]`
- `actions`: 动作 `[N]`
- `rewards`: 奖励 `[N]`（N-step 累积奖励）
- `next_obs`: 下一观测窗口 `[N, window_size, obs_dim]`
- `dones`: 终止标志 `[N]`
- `delta_targets`: 辅助预测目标 `[N]`

## 离线学习 vs 在线学习

### 离线学习的优势

- ✅ **数据效率**：充分利用历史数据
- ✅ **稳定性**：训练过程不受环境变化影响
- ✅ **可复现性**：固定数据集，结果可复现
- ✅ **安全性**：适合实际部署场景（不能在线探索）

### 离线学习的挑战

- ⚠️ **分布偏移**：数据收集策略与学习策略可能不同
- ⚠️ **数据质量**：需要高质量的数据集
- ⚠️ **超参数调优**：CQL 的 alpha 需要仔细调整

## CQL（Conservative Q-Learning）

CQL 是一种保守性约束方法，用于防止离线学习中对分布外动作的过度估计。

### 何时使用 CQL

- ✅ 数据收集策略与学习策略差异较大时
- ✅ 数据集覆盖不完整时
- ✅ 需要更稳定的训练时

### CQL Alpha 调优建议

- **小数据集**：alpha = 0.1 - 0.2
- **大数据集**：alpha = 0.05 - 0.1
- **分布偏移大**：alpha = 0.2 - 0.5

## 模型修改说明

### 确定性模式

离线学习模式下，模型自动禁用 NoisyNet，使用普通的 Linear 层：

```python
model = RainbowWithForecast(
    ...,
    use_noisy=False  # 离线学习不使用 NoisyNet
)
```

### 模型保存

离线训练的模型保存在 `checkpoints/` 目录：

- `rainbow_offline_epoch_{N}.pth` - 定期保存的检查点
- `rainbow_offline_final.pth` - 最终模型

## 常见问题

### Q: 需要收集多少数据？

A: 建议至少 100-200 个 episode，约 10,000-50,000 个样本。

### Q: 使用哪种收集策略？

A: 推荐使用 `uniform_mix`，可以覆盖更多的动作空间。

### Q: CQL Alpha 如何选择？

A: 从 0.1 开始，根据训练效果调整。如果损失过大，减小 alpha；如果性能不佳，增大 alpha。

### Q: 离线训练和在线训练的性能对比？

A: 离线训练通常更稳定，但可能性能略低于在线训练（取决于数据质量）。
