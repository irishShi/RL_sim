# 离线训练模型测试指南

## 概述

`test_rainbow_offline.py` 是专门用于测试离线训练得到的 Rainbow DQN 模型的脚本。它支持：

- ✅ 自动检测和加载离线训练模型
- ✅ 显示离线训练相关信息（CQL、epoch等）
- ✅ 与传统 A3 算法对比
- ✅ 与在线训练模型对比（可选）
- ✅ 生成可视化对比图表

## 快速开始

### 基本用法

```bash
# 测试离线训练模型（自动查找 rainbow_offline_final.pth）
python test_rainbow_offline.py

# 指定检查点文件
python test_rainbow_offline.py --checkpoint checkpoints/rainbow_offline_epoch_100.pth

# 测试更多 episode
python test_rainbow_offline.py --num_episodes 20

# 保存对比图表
python test_rainbow_offline.py --save_plots
```

## 参数说明

### 必需参数

无（脚本会自动查找离线训练模型）

### 可选参数

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `--checkpoint` | str | None | 指定检查点文件路径（默认：自动查找） |
| `--num_episodes` | int | 10 | 每个策略测试的 episode 数量 |
| `--seed` | int | 42 | 随机种子 |
| `--compare_online` | flag | False | 是否与在线训练模型对比 |
| `--compare_traditional` | flag | True | 是否与传统 A3 算法对比 |
| `--save_plots` | flag | False | 是否保存对比图表 |

## 模型查找逻辑

脚本按以下顺序查找离线训练模型：

1. **指定的检查点**（如果使用 `--checkpoint`）
2. **`rainbow_offline_final.pth`**（最终模型）
3. **`rainbow_offline_epoch_*.pth`**（最新的 epoch 模型）

## 输出说明

### 1. 模型信息

加载模型时会显示：
- 训练轮数（epoch）
- 训练步数（step）
- 是否使用 NoisyNet（离线训练为 False）
- 是否使用 CQL
- CQL Alpha 值（如果使用）

### 2. 测试结果

每个 episode 显示：
- 总奖励
- 切换次数
- 平均 SINR
- 最小 SINR

### 3. 性能统计

- 平均奖励（含标准差）
- 平均切换次数
- 平均 SINR

### 4. 对比结果

如果启用对比，会显示：
- 各策略的平均奖励
- 各策略的切换次数
- 各策略的平均 SINR
- 各策略的最小 SINR

## 可视化输出

如果使用 `--save_plots`，会生成包含以下内容的对比图：

1. **RSRP 曲线与切换点**：显示信号强度和切换时机
2. **SINR 对比**：对比不同策略的 SINR 表现
3. **参数选择**：显示离线训练模型的 Hys/TTT 选择
4. **性能对比柱状图**：综合性能对比

图表保存为：`test_results_offline_comparison.png`

## 与传统测试脚本的区别

| 特性 | `test_rainbow.py` | `test_rainbow_offline.py` |
|------|-------------------|--------------------------|
| 目标模型 | 在线训练模型 | 离线训练模型 |
| 模型查找 | `rainbow_final.pth` | `rainbow_offline_final.pth` |
| NoisyNet | 可能使用 | 不使用（False） |
| CQL 信息 | 不显示 | 显示 |
| 训练信息 | Episode | Epoch/Step |
| 离线训练标记 | 无 | 自动识别 |

## 常见问题

### Q: 找不到离线训练模型？

**A:** 确保已运行 `train_rainbow_offline.py` 并生成了模型文件。检查：
```bash
ls checkpoints/rainbow_offline*.pth
```

### Q: 如何测试特定 epoch 的模型？

**A:** 使用 `--checkpoint` 参数：
```bash
python test_rainbow_offline.py --checkpoint checkpoints/rainbow_offline_epoch_50.pth
```

### Q: 如何与在线训练模型对比？

**A:** 使用 `--compare_online` 参数：
```bash
python test_rainbow_offline.py --compare_online
```
注意：需要先有在线训练的模型文件 `rainbow_final.pth`

### Q: 测试结果不稳定？

**A:** 增加测试 episode 数量：
```bash
python test_rainbow_offline.py --num_episodes 50
```

### Q: 如何保存测试结果？

**A:** 使用 `--save_plots` 保存图表，或重定向输出：
```bash
python test_rainbow_offline.py > test_results.txt
```

## 性能评估指标

脚本会评估以下指标：

1. **总奖励**：累积奖励值（越高越好）
2. **切换次数**：切换频率（适中最好）
3. **平均 SINR**：平均信号质量（越高越好）
4. **最小 SINR**：最差信号质量（越高越好）
5. **Outage 次数**：信号中断次数（越少越好）

## 最佳实践

1. **首次测试**：使用默认参数快速验证模型
2. **详细评估**：使用 `--num_episodes 20` 或更多
3. **对比分析**：启用 `--compare_traditional` 和 `--compare_online`
4. **结果保存**：使用 `--save_plots` 保存可视化结果
