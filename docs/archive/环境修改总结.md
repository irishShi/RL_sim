## 一、修改内容

### 1.1 `envs/ho_logic.py` - 扩展切换逻辑

**新增功能**：
- ✅ `update_hys_ttt(hys, ttt)`: 更新 Hys 和 TTT 参数
- ✅ `check_a3_event(delta_rsrp, dt)`: 检查 A3 事件并更新 TTT 计时器
- ✅ `execute_handover_with_a3(...)`: 新接口，支持 A3 事件和 TTT
- ✅ `get_current_params()`: 获取当前 Hys/TTT 参数

**状态管理**：
- `current_hys`: 当前 Hys 参数（dB）
- `current_ttt`: 当前 TTT 参数（ms）
- `ttt_timer`: TTT 计时器（秒）
- `a3_condition_met`: A3 事件条件是否满足

### 1.2 `envs/train_ho_env.py` - 修改主环境

**动作空间变更**：
```python
# 修改前
self.action_space = spaces.Discrete(2)  # 0=不切换, 1=切换

# 修改后
self.action_space = spaces.Discrete(48)  # 0-47: Hys/TTT 组合
```

**新增配置选项**：
```python
self.use_hys_ttt = self.cfg.get("use_hys_ttt", True)  # 默认启用
```

**step 方法修改**：
- 如果 `use_hys_ttt=True`：根据 Hys/TTT 参数判断切换
- 如果 `use_hys_ttt=False`：兼容模式，保持旧的 2 动作行为

**新增 info 字段**：
- `delta_rsrp_dbm`: RSRP 差值（用于辅助预测）
- `current_hys`: 当前 Hys 参数
- `current_ttt`: 当前 TTT 参数
- `a3_condition_met`: A3 条件是否满足
- `ttt_timer`: TTT 计时器值

## 二、使用方法

### 2.1 基本使用（推荐）

```python
from envs.train_ho_env import TrainHandoverEnv

# 创建环境（默认使用 Hys/TTT 模式）
env = TrainHandoverEnv(config_path="configs/default_env_config.yaml")

# 动作空间现在是 48 个动作
print(env.action_space)  # Discrete(48)

# 使用模型选择动作（0-47）
action = model.act(obs)  # 例如：action = 10

# 执行动作
obs, reward, done, truncated, info = env.step(action)

# info 中包含当前参数
print(f"Hys: {info['current_hys']} dB")
print(f"TTT: {info['current_ttt']} ms")
print(f"ΔRSRP: {info['delta_rsrp_dbm']} dB")
```

### 2.2 兼容模式（如果需要）

```python
# 在配置文件中设置
config = {
    "use_hys_ttt": False,  # 使用旧的 2 动作模式
    # ... 其他配置
}

env = TrainHandoverEnv(config=config)
# 现在动作空间是 Discrete(2)
```

### 2.3 动作到参数的转换

环境内部会自动将动作索引转换为 Hys/TTT 参数：

```python
# 动作映射（48 个动作）
# 动作 0:  (Hys=1.5, TTT=0)
# 动作 1:  (Hys=1.5, TTT=40)
# ...
# 动作 10: (Hys=2.0, TTT=160)
# ...
# 动作 47: (Hys=5.0, TTT=640)
```

如果需要手动转换，可以使用 `ActionSpace`：

```python
from models.action_space import ActionSpace

action_space = ActionSpace()
hys, ttt = action_space.action_to_hys_ttt(10)  # (2.0, 160.0)
```

## 三、切换逻辑说明

### 3.1 A3 事件

**条件**：`RSRP_neig - RSRP_serv > Hys`

当邻区信号比服务小区信号强超过 Hys 阈值时，触发 A3 事件。

### 3.2 TTT（Time-To-Trigger）

**机制**：
1. A3 条件满足时，启动 TTT 计时器
2. 如果 A3 条件持续满足，计时器累积
3. 如果 A3 条件不满足，计时器重置
4. 当计时器达到 TTT 阈值时，执行切换

**单位**：TTT 参数单位是毫秒（ms），内部转换为秒（s）

### 3.3 保护时间（T_guard）

即使满足 A3 和 TTT 条件，如果距离上次切换时间小于 `T_guard_s`，也不会执行切换。

## 四、优势

### 4.1 代码更简洁

**修改前**（需要包装器）：
```python
env = TrainHandoverEnv()
wrapper = HandoverWrapper(env, action_space)
obs, reward, done, info = wrapper.step(action)
```

**修改后**（直接使用）：
```python
env = TrainHandoverEnv()
obs, reward, done, info = env.step(action)
```

### 4.2 更符合实际系统

- 实际 5G 系统就是通过设置 Hys/TTT 参数来控制切换
- 环境直接支持参数化切换更真实

### 4.3 更好的封装

- 切换逻辑完全封装在环境内部
- 外部调用者不需要了解实现细节

## 五、注意事项

所有使用环境的地方都需要知道动作空间从 2 变为 48。

如果需要在某些场景下使用旧的 2 动作模式，可以设置 `use_hys_ttt=False`。
